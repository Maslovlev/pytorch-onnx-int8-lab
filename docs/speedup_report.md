# ДЗ #7: Seaborn barplot - Speed-up PyTorch vs ONNX vs INT8

## Задание
Построить график speed-up PyTorch vs ONNX vs INT8 и сохранить docs/speedup.png.

## Результаты:

| Фреймворк | Время (сек) | Speed-up vs PyTorch |
|-----------|-------------|---------------------|
| PyTorch-GPU | 2.541 | 1.000x |
| ONNX-CPU | 7.892 | 0.322x |
| ONNX-GPU | 2.823 | 0.900x |
| ONNX-CPU-INT8 | 6.514 | 0.390x |

## График:
Создан график с двумя панелями:
1. **Левая панель**: Время инференса для каждого фреймворка
2. **Правая панель**: Коэффициент ускорения относительно PyTorch

## Файлы:
- `docs/speedup.png` - график сравнения производительности

## Выводы:
- ONNX-GPU показывает производительность, близкую к PyTorch
- ONNX-CPU работает медленнее из-за отсутствия GPU ускорения
- INT8 квантизация на CPU обеспечивает баланс между скоростью и точностью
