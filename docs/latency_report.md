# ДЗ #5: Измерение Latency одной картинки (100 прогонов)

## Задание
Измерить latency (время отклика) одной картинки за 100 прогонов модели.

## Параметры измерения:
- **Модель**: EfficientNet-B3 (предобученная)
- **Устройство**: cpu
- **Количество прогонов**: 100
- **Разрешение изображения**: 224x224
- **Датасет**: CIFAR-10 (валидационный набор)

## Результаты измерений:

### Статистика latency:
| Показатель | Значение |
|------------|----------|
| **Средняя latency** | 64.49 ms |
| **Стандартное отклонение** | 13.92 ms |
| **Минимальная latency** | 50.46 ms |
| **Максимальная latency** | 106.10 ms |
| **95-й перцентиль** | 86.72 ms |
| **99-й перцентиль** | 99.47 ms |

### Производительность:
- **Устройство**: CPU (GPU недоступен)

## Анализ результатов:
1. **Стабильность**: Стандартное отклонение 13.92 ms (21.6% от среднего)
2. **Производительность**: Низкая latency для CPU
3. **Воспроизводимость**: 95% прогонов имеют latency менее 86.72 ms

## Выводы:
Latency модели EfficientNet-B3 на CPU составляет в среднем 64.49 ms за прогон.
Для real-time приложений рекомендуется оптимизация или использование более легкой модели.
