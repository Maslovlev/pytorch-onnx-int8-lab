# Лабораторная работа: PyTorch → ONNX → INT8

## Компьютерное зрение, 4-й модуль

### Задания:
1. **dz0** - Настройка окружения
2. **dz1** - Информация о GPU
3. **dz2** - Обучение модели на CIFAR-10
4. **dz3** - Экспорт модели в ONNX
5. **dz4** - Сравнение производительности
6. **dz5** - Квантизация в INT8

### Структура проекта:
- `notebooks/` - Jupyter ноутбуки с исследованиями
- `docs/` - документация и отчеты по заданиям
- `scripts/` - Python скрипты
- `models/` - сохраненные модели (.pth, .onnx)
- `data/` - датасеты
- `reports/` - результаты измерений
